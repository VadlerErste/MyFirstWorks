# MyFirstWorks
Работаю в крупной региональной компании в сфере ТЭК, разрабатываю аналитические дашборд-отчеты в YandexDatalens и Apache Superset разного профиля задач.
Подготавливаю и обрабатываю сырые данные под конкретные задачи с помощью библиотеки Pandas в программной оболочке JupiterNotebоok, формирую аналитические записки для выдачи рекомендаций по ad-hoc запросам руководства.
